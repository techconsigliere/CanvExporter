Canvas course exporter

Saves a Canvas course as Word documents and spreadsheets, in a folder on your computer.

Install it

  1. Show your bookmarks bar. Chrome and Edge: Ctrl+Shift+B, or Cmd+Shift+B on a Mac.
  2. Drag the blue button below onto that bar.

Export Canvas course

If dragging does not work, right-click your bookmarks bar, choose Add page, name it anything, and paste the text at the bottom of this page into the URL field.

Use it

  1. Open the Canvas course you want to save and sign in as you normally would.
  2. Click Export Canvas course on your bookmarks bar.
  3. Choose what to include, then click Choose folder and export.
  4. Pick a folder when your browser asks. It opens at your Desktop, so you can select the Desktop itself and a new course folder will be created inside it. Choose Save changes or Allow when asked for permission to write there.
  5. Leave the tab alone until it says Done.
Folder saving needs Chrome or Edge. In Firefox or Safari the export still runs, but it arrives as a single .zip file in your Downloads folder instead of a folder tree.

What it saves

Assignments, classic quizzes with matching answer keys, question banks, rubrics, discussions, announcements, pages, and the syllabus, all as Word documents. Rubrics also come out as importable spreadsheets, and the gradebook as a spreadsheet if you tick that option.

New Quizzes assessments cannot be saved this way — Canvas does not make their questions available — so you get a short note listing which ones you will need to handle yourself.

Nothing is sent anywhere. The tool talks only to Canvas, signed in as you, and can only reach courses you already have access to.
